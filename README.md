# TEMUshangjia

A reusable Codex skill for preparing, validating, publishing, and verifying TEMU semi-managed product listings from spreadsheets and reference images.

Copy this repository to a Codex skills directory as `temu-shangjia`, then invoke `$temu-shangjia`. Supply TEMU credentials only through the runtime environment variables documented in `SKILL.md`; never commit credentials or listing responses.
